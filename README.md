# 🚀 Machine Learning Projects

A curated collection of hands-on machine learning projects that focus on understanding algorithms deeply, including **from-scratch implementations**, **classical ML**, **NLP**, and **computer vision**.

---

## 📚 Projects in this repository

| Project | Focus | Highlights |
|---|---|---|
| [Gradient Descent and LR from scratch](./Gradient%20Descent%20and%20LR%20from%20scratch/) | Optimization + Regression | MSE and gradients from scratch, SGD, regularization, Huber loss |
| [Gradient Boosting and Clusterisation from scratch](./Gradient%20Boosting%20and%20Clusterisation%20from%20scratch/) | Boosting + Clustering | Gradient boosting from scratch, DBSCAN from scratch, flight-delay experiments |
| [Knn and Linear Regression](./Knn%20and%20Linear%20Regression/) | Classification + Regression | kNN decision boundaries, linear regression, multicollinearity, Ridge/Lasso |
| [NLP Classification](./NLP%20Classification/) | Natural Language Processing | Disaster tweet classification, custom tokenization, CountVectorizer vs TF-IDF |
| [YOLO from scratch](./YOLO%20from%20scratch/) | Object Detection | YOLOv1-style detector in PyTorch, custom loss, bounding box prediction |

## ▶️ Getting started

1. Clone the repository.
2. Open any project folder.
3. Read the project-specific README.
4. Run the notebook (`.ipynb`) in Jupyter or Google Colab.
